# 채용 공고 에이전트

2월 졸업예정자를 위한 네트워크/통신, 클라우드, 인프라, AI, IT/전산 직무 인턴·신입 채용 공고 자동 수집·정리 에이전트입니다.

## 구성

- **대시보드**: [채용 공고 에이전트 (Notion)](https://app.notion.com/p/3d47817e40bd8151a2bbc5e3e3bba3b9)
  - [채용 공고 트래커](https://app.notion.com/p/b00f32e9369d492980881fb0b7db5b8a) — 공고 목록 DB (기업/직무분야/고용형태/마감일/출처/공고링크/2월졸업 지원가능/지원상태/자소서 초안 여부)
  - [내 이력 정보 (자소서용)](https://app.notion.com/p/3d47817e40bd81e7bd15eedd2218718e) — 자소서 초안 작성에 쓰이는 본인 이력/경험 정보
- **자동 실행 (Routine)**: 매일 KST 08:20에 실행되어
  1. 이력 정보를 확인하고
  2. 사람인/잡코리아/원티드에서 네트워크·클라우드·인프라·AI·IT전산 직무의 인턴/신입 공고를 검색하고
  3. 신규 공고를 트래커 DB에 추가하고 (2월 졸업예정자 지원 가능 여부 포함)
  4. 이력 정보가 채워져 있으면 마감 임박 공고부터 자소서 초안을 작성합니다.

## 사용 방법

1. Notion의 "내 이력 정보 (자소서용)" 페이지에 전공/경험/기술스택/수상 등을 채워 넣으면, 다음 실행부터 해당 정보를 바탕으로 자소서 초안이 작성됩니다.
2. "채용 공고 트래커"에서 마감일순 정렬로 지원 일정을 관리하고, 지원 상태를 갱신합니다.
3. 대상 채용 소스나 검색 키워드를 조정하고 싶으면 Routine 프롬프트를 수정합니다.
