### 전반부 복습 핵심
- 알고리즘을 배우는 이유 = **상황에 맞는 효율적인 알고리즘**을 고르기 위해
  - 예: 이미 정렬된 데이터라면 퀵 정렬(끝 피벗)은 O(n²), 버블·삽입은 O(n) → **"항상 빠른" 알고리즘은 없음**

- 비교 기반 정렬은 아무리 빨라도 **n lg n**, 비비교 정렬은 O(n)이지만 **제약이 많음**
## 6주차 ② (10/8) 연습 문제 풀이 ①

### 1. 퀵 정렬 Partition 주의점 🔥
- 개념적으로는 "작은 건 왼쪽, 큰 건 오른쪽에 끼워 넣기(밀기)"지만, **실제 코드는 원소를 밀지 않고 두 원소를 교환(swap)** 함
  - 예: 9 4 7 1 … 에서 1이 왼쪽으로 가야 할 때 → 한 칸씩 밀지 않고 **1과 9의 위치만 교환**
- 그래서 결과 순서가 직관과 다를 수 있음 → 🔥 **시험에서 코드대로 추적한 학생이 적어 정답률이 낮았음**

### 2. 삽입 정렬 반복 횟수 (CLRS 의사코드)

| INSERTION-SORT(A) | 비용 | 반복 횟수 |
|---|---|---|
| for j = 2 to n | c₁ | **n** |
| key = A[j] | c₂ | **n − 1** |
| i = j − 1 | c₃ | **n − 1** |
| while i > 0 and A[i] > key | c₄ | **Σⱼ₌₂ⁿ tⱼ** |
| A[i+1] = A[i] | c₅ | **Σⱼ₌₂ⁿ (tⱼ − 1)** |
| i = i − 1 | c₆ | **Σⱼ₌₂ⁿ (tⱼ − 1)** |
| A[i+1] = key | c₇ | **n − 1** |

- tⱼ = j번째 key에 대해 while 조건을 검사한 횟수
- Best(정렬됨): tⱼ = 1 → **O(n)** / Worst(역순): tⱼ = j → Σ ≈ n²/2 → **O(n²)** / Average: **O(n²)**
- **In-place인 이유**: 추가 메모리 없이 **배열 안에서** key를 옮기며 정렬하기 때문

### 3. 병합 정렬 결합 과정 (6 3 5 8 1 7 4 2)
```
[6][3][5][8][1][7][4][2]
→ [3 6] [5 8] [1 7] [2 4]
→ [3 5 6 8]   [1 2 4 7]
→ [1 2 3 4 5 6 7 8]
```
🔥 **병합이 O(n)인 이유**: 두 정렬된 리스트에 **포인터(플래그) 두 개**를 두고, 작은 쪽을 올리고 그 포인터만 한 칸 이동 → **원소 수만큼만** 움직임

### 4. 점근 표기법 성질 복습
- 추이성: 5개 모두 / 반사성: **O, Ω, Θ만** (o, ω는 자기 자신과 같을 수 없음) / 대칭성: **Θ만** / 전치 대칭: (O, Ω), (o, ω)

### 5. 🔥 참/거짓 판별 (f, g는 점근적으로 음이 아닌 함수)
💡 **거짓을 보이려면 반례 하나만 찾으면 됨** (1차·2차 함수처럼 단순한 걸로)

| 명제 | 답 | 이유 |
|---|---|---|
| f = O(g) 이면 g = O(f) | **거짓** | f = n, g = n² → n = O(n²) 이지만 n² ≠ O(n) |
| f = O(g) 이면 g = Ω(f) | **참** | 전치 대칭성 (f ≤ g ⇔ g ≥ f) |
| f = O(g) 이면 2^f = O(2^g) | **거짓** | f = 2n, g = n → 2n = O(n) 이지만 2²ⁿ = 4ⁿ ≠ O(2ⁿ) |

> ⚠️ 다항식에서는 **계수(상수)가 무시**되지만, **지수(또는 로그) 안으로 들어가면 무시되지 않는다!**
> (2n과 n은 같은 O(n)이지만 2^(2n) = 4ⁿ 과 2ⁿ 은 다름)

### 6. 재귀 트리 복습: T(n) = 2T(n/2) + n
- 💡 이 꼴을 보면 **병합 정렬** → 답이 n lg n 이라는 걸 바로 알 수 있음
- 레벨당 비용: n, n, n, … (모든 레벨이 n)
- 높이: (1/2)ᵏ n = 1 → **k = log₂ n**
- 전체: n · log₂ n = **O(n lg n)**
- 🔥 "복잡도를 구하시오"면 재귀 트리 / 마스터 정리 아무거나, **방법이 지정되면 그 방법으로**
